# МИДИС

Сайт компьютерного клуба МИДИС в Саратове.

Сайт: https://wedding-postcards.github.io/MIDISWS/

## Локальный запуск

Node.js 22: npm ci, затем npm run dev.
Сборка: npm run build. Результат находится в dist.

GitHub Pages автоматически публикуется при обновлении main.
Источники материалов и лицензии указаны в SOURCES.md и public/assets.
