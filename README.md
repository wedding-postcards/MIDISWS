# МИДИС — тестовый шаблон сайта

Демонстрационный макет сайта компьютерного клуба «МИДИС» для согласования с заказчиком. Это не итоговая версия: дизайн, содержание и функции будут доработаны. Первый экран показывает Персея, чашу и интерактивные монеты; следующий экран пока служит пустой заглушкой. Кнопка бронирования также пока является заглушкой. Сайт собран на Vite, Three.js и TypeScript.

## Локальный запуск

Нужны Node.js 22 и браузер с WebGL 2.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. `npm run build` создаёт готовые статические файлы в `dist/`; `npm run preview` показывает сборку локально.

## GitHub

В репозитории находятся исходники проекта. Папки `node_modules/`, `dist/`, `.npm-cache/`, `assets/`, `qa/`, `research/` и `blender/` исключены в `.gitignore`.

Для GitHub Pages откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**, затем вручную запустите **Actions → Publish MIDIS to GitHub Pages → Run workflow**. Публикация не запускается автоматически при загрузке репозитория. Относительные пути позволяют разместить сайт в репозитории с любым именем.

Исходные донорские материалы и данные об их происхождении перечислены в [SOURCES.md](SOURCES.md). Среди них есть файлы Shopify, используемые для анимации и освещения первого экрана. Право на их публичное распространение и коммерческое использование пока не подтверждено; перед дальнейшим использованием нужно получить разрешение либо заменить эти материалы своими.
